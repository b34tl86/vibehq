## ⚡ Why VibeHQ?

When you're **vibe coding** with modern agentic harnesses (**Claude Code**, **Antigravity**, **Cursor**, **OpenAI Swarm**), your helpers work invisibly behind walls of terminal output or hidden background JSON logs.

* ❌ **The Blindfold:** You don't know who is running what, which specialist is waiting, or when subagents finish.
* ❌ **The Coordination Problem:** Every project needs different roles (designers, backend devs, security auditors, QA fuzzers), but setting up agent prompts by hand is tedious.
* ❌ **Static Overhead:** Traditional dashboards are rigid, boring, and disconnected from your code.

**VibeHQ solves this with three intelligent steps:**
1. **🔍 Auto-Analyzes Your Repo**: Inspects your stack (languages, frameworks, auth, database, tests) in seconds.
2. **🤝 Auto-Hires Your Squad**: Automatically drafts the ideal specialized AI agents and generates your workspace directives (`CLAUDE.md`, `GEMINI.md`, `AGENTS.md`).
3. **🏢 Procedurally Generates Your Campus**: Builds a custom, animated isometric studio that **dynamically scales its grid dimensions** to fit your team size—with zero overlapping seats and real-time live telemetry.

## 🚀 Quickstart

Run VibeHQ in **any repository** in less than 30 seconds.

### Method 1: Python CLI (Recommended)

```bash
# 1. Install directly from GitHub
pip install git+https://github.com/b34tl86/vibehq.git

# 2. Navigate to any project you want to vibe code
cd ~/projects/my-awesome-app

# 3. Analyze codebase & auto-hire the matching AI squad
vibehq init

# 4. Launch your live virtual office
vibehq start
```

### Method 2: Zero-Install via `uvx` (Fast Modern Python)

```bash
cd ~/projects/my-awesome-app

# Run instantly without permanent installation
uvx --from git+https://github.com/b34tl86/vibehq.git vibehq init
uvx --from git+https://github.com/b34tl86/vibehq.git vibehq start
```

### Method 3: Node / npx (JavaScript & Web Developers)

```bash
cd ~/projects/my-awesome-app
npx vibehq init
npx vibehq start
```

## 🏢 Procedural Office Scaling

VibeHQ doesn't squeeze 10 people into a broom closet or strand 2 people in an empty warehouse. The layout generator dynamically scales the grid and room architecture to fit your squad:

| Staff Size | Campus Archetype | Grid Dimensions | Partitioned Wings |
| :--- | :--- | :--- | :--- |
| **1 – 3 Staff** | **Compact Startup Loft** | `16 × 14` tiles | Open-plan studio, shared espresso café bar, pair programming bench |
| **4 – 7 Staff** | **Mid-Size Tech Studio** | `24 × 20` tiles | Executive suite, UI studio, bullpen, QA lab, Cyber SOC, server vault, war room |
| **8+ Staff** | **Enterprise Tech Campus** | `32 × 26` tiles | Multi-wing corridors, dedicated departmental pods, grand atrium, amphitheater |

* **Zero Collision Guarantee**: Workstations maintain $\ge 3$ tiles of clearance with dedicated walking lanes.
* **Ephemeral Contractor Despawn**: When temporary subagents (guest contractors) finish a task and celebrate, they pack up and depart the office so your campus stays clean and uncluttered.

## 📋 CLI Reference

```
Usage: vibehq <command> [options]

Commands:
  init      Analyze repository, hire specialist squad, and generate AI directives
  status    Print current squad roster, tech profile, and campus grid archetype
  start     Launch live virtual office and start telemetry daemon

Options:
  --dir <path>     Target repository directory (default: current directory)
  --port <number>  Port for visualizer server (default: 8484)
  --host <string>  Host interface to bind (default: 127.0.0.1)
  --no-open        Do not open the browser automatically
```

## 🔌 Multi-Harness Telemetry

VibeHQ ships with universal pluggable telemetry adapters that stream live state with zero configuration:

1. **Claude Code Adapter**: Automatically reads `~/.claude/projects/.../subagents/*.jsonl` session logs.
2. **Antigravity / Gemini Adapter**: Parses tool use events, agent switches, and task completions.
3. **Universal Git Watcher (Fallback)**: Inspects live branches, uncommitted file diffs, and commit author streams on any git repo.

## 🛡️ Zero-Pollution & Privacy Guarantee

* **Zero Code Tampering**: VibeHQ never modifies your application's source code. It only manages `.vibehq/squad.json` and updates Markdown AI rules (`CLAUDE.md`, `GEMINI.md`).
* **100% Local & Offline**: All telemetry processing, canvas rendering, and server endpoints run strictly on `127.0.0.1`. No code, files, or tokens are ever uploaded to third-party servers.
